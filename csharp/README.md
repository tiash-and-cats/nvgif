# NVGIF C# demo

> [!TIP]  
> The `.csproj` given uses .NET 10, which you might not have. Adjust it to your .NET version (e.g. `net8.0-windows`).
> This demo uses the NVGIF C# implementation, so you need `System.Drawing.Common` installed. As such, it is Windows-specific.

To run the demo, do:
``` batch
dotnet run
```

It will run the demo and open a WinForms window which shows the demo file `images/example.nvg4`.
